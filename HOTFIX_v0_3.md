# Fetchuccini — Hotfix / UI v0.3

Cambios incluidos:
- La aplicación ahora se llama **Fetchuccini**.
- Nuevo filtro **Tienda** (Todas o una tienda específica).
- Nuevo botón **Ordenar precio** para alternar entre Menor → Mayor y Mayor → Menor.
- El orden de precio agrupa por moneda antes de ordenar, para no tratar ARS y USD como si fueran comparables directamente.
- Incluye también los arreglos de v0.2 para Pirulo y La Batikueva.
