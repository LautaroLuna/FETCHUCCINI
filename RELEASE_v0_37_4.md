# Fetchuccini v0.37.4

## MagicDealers: stock-only origin search

- MagicDealers now uses CrystalCommerce Advanced Search as the primary search endpoint.
- Adds `search[in_stock]=1`, so sold-out publications are filtered by MagicDealers before Fetchuccini paginates them.
- Keeps sequential pagination and the existing relevance stop: once a page contains no matching card name, pagination ends.
- Pagination links generated by CrystalCommerce preserve the stock filter.
- Keeps the persistent TLS session introduced in v0.37.2.
- Falls back to the proven `/products/search` path if Advanced Search errors or its template is no longer recognizable.
- Adds a regression test proving the adapter sends the stock-only advanced-search parameters.
- Diagnostic pagination logs now include `mode=advanced-in-stock`.

Expected effect: broad MagicDealers searches should use far fewer pages/requests while preserving all in-stock matching printings.
